# Tarea 6 — Proyecto Final: DML (EA6)

Entregables finales del proyecto de aula (Red Social Pascualina): poblamiento masivo de tablas, manipulación de datos semi-estructurados (JSON), consultas con JOINs y funciones de agregación, vistas, consultas parametrizadas (`PREPARE` / `EXECUTE`), evaluación de rendimiento (`EXPLAIN ANALYZE`), validación de propiedades ACID y respaldo físico en PostgreSQL.

> **Nota de estructura:** Todos los entregables se encuentran directamente en la raíz de `Tarea6/` (sin subcarpetas).
